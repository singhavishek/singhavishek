I'm an AI engineer working on enterprise LLM systems, multi-agent architectures, and the math that makes them reliable. I did my PhD in physics (quantum many-body systems with unsupervised deep learning), and I still think the most interesting problems live where rigorous mathematics meets messy production engineering.

These days I work on agentic AI platforms and computer-vision / LLM verification systems, and I care a lot about the things that make AI systems actually trustworthy in production: tracing and observability, clean agent contracts, and predictable delivery.

### What I'm into

- **Agentic AI** — multi-agent state machines, orchestration, FastAPI + PostgreSQL backends
- **LLM observability** — distributed tracing, evaluation, getting span structures right
- **The physics → AI bridge** — diffusion models (VP-SDE), PINNs, equivariant networks
- **Developer tooling** — reusable MCP servers, Claude Code workflows, things that make engineers faster
- **Quant / markets** — analyzing Indian equities with a homegrown computation layer
